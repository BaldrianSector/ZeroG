# 🧑‍🚀 ZeroG

**ZeroG** is a personal test project made to help me learn **Unity**. In this experimental space exploration game, you take control of a lone astronaut floating in zero gravity outside a spacecraft.

The focus of the project is to explore Unity’s physics, input systems, and 3D environment tools — while building something fun and interactive along the way.

## 🎮 Concept

You're an astronaut adrift in space, navigating in zero gravity using thrusters. There's no up or down — just the vast emptiness around you. Your movement, momentum, and orientation all depend on how you control your suit in a true zero-G environment.

This project is not a full game (yet), but a playground for learning and prototyping mechanics such as:

- Zero-gravity character movement
- Camera control in 3D space
- Object interaction
- Physics-based drifting and momentum
